# Run Hash Race

Hash Race does **not** need CMake, Visual Studio, WSL, or terminal commands to play the Unity prototype.

## First run

1. Install a current Unity 6 editor through Unity Hub.
2. In Unity Hub choose **Add project from disk** and select the cloned or downloaded `HashRace` folder.
3. Open the project.
4. Hash Race automatically creates `Assets/Scenes/Main.unity` the first time the editor finishes importing the project.
5. Open `Main.unity` if it is not already open.
6. Press the **Play** triangle at the top of Unity.

The first screen is intentionally simple. It is the engineering and economy prototype, not the final art style.

## What you can do now

- Watch simulated days pass.
- Change time to 1x, 5x, or 20x.
- Buy the newest ASIC you have unlocked.
- Sell hardware when you need cash.
- Fund R&D.
- Unlock increasingly powerful and efficient machine generations.
- Watch Bitcoin price, network hashrate, and electricity price move over time.
- Compete against three AI mining companies.
- Buy rival companies when you have enough capital.
- Race toward PH/s, 100 PH/s, sub-1 J/TH, and EH/s-scale milestones.

## If the Main scene is missing

Use the Unity menu:

`Hash Race > Repair First Playable Setup`

That command recreates the basic scene and adds it to the build settings.
